Мұғалім: Күнгөзин Дәулет Бағдашұлы

Спецкурс · 8 «Ә» класс · Алгебра · 8.2.2.4
Учитель математики: Кунгозин Даулет Багдашұлы

Виет теоремасына кері теорема. Виет теоремасын қолдану

Теорема, обратная теореме Виета. Применение теоремы Виета

1. Теория

Келтірілген квадрат теңдеу: x² + px + q = 0 (мұндағы a = 1).

Приведённое квадратное уравнение: x² + px + q = 0 (здесь a = 1).

Виет теоремасы. Егер x₁ және x₂ — теңдеудің түбірлері болса, онда x₁ + x₂ = −p, x₁ · x₂ = q.

Теорема Виета. Если x₁ и x₂ — корни уравнения, то x₁ + x₂ = −p, x₁ · x₂ = q.

Кері теорема. Егер x₁ + x₂ = −p және x₁ · x₂ = q болса, онда x₁ және x₂ — x² + px + q = 0 теңдеуінің түбірлері.

Обратная теорема. Если x₁ + x₂ = −p и x₁ · x₂ = q, то x₁ и x₂ — корни уравнения x² + px + q = 0.

Жалпы түрі: ax² + bx + c = 0 үшін x₁ + x₂ = −b/a, x₁ · x₂ = c/a.

Общий вид: для ax² + bx + c = 0 имеем x₁ + x₂ = −b/a, x₁ · x₂ = c/a.

Есте сақта: қосындының алдында минус таңбасы бар (−p); көбейтінді таңбасы өзгермейді (q).

Запомни: у суммы корней знак меняется на противоположный (−p), у произведения знак тот же (q).

Алгоритм: 1) p мен q-ді анықта; 2) қосынды −p мен көбейтіндіні q жаз; 3) осындай екі санды теріп тап; 4) тексер.

Алгоритм: 1) определи p и q; 2) запиши сумму −p и произведение q; 3) подбери два таких числа; 4) сделай проверку.

Есеп 1. x² − 5x + 6 = 0

p = −5, q = 6. Қосынды: x₁ + x₂ = 5; көбейтінді: x₁ · x₂ = 6.

Көбейтіндісі 6 сандар: 1·6, 2·3. Қосындысы 5 болатыны — 2 және 3.

p = −5, q = 6. Сумма 5, произведение 6. Пары с произведением 6: 1·6, 2·3. Сумма 5 у пары 2 и 3.

Тексеру: 2² − 5·2 + 6 = 4 − 10 + 6 = 0 ✓; 3² − 15 + 6 = 0 ✓.

Жауабы / Ответ: 2; 3

Есеп 2. x² + 7x + 10 = 0

p = 7, q = 10. Қосынды: −7; көбейтінді: 10.

Көбейтінді оң, қосынды теріс ⇒ екі сан да теріс. 10 = 2·5, қосындысы −7 ⇒ −2 және −5.

p = 7, q = 10. Сумма −7, произведение 10. Произведение положительное, сумма отрицательная — оба числа отрицательные. Подходит −2 и −5.

Тексеру: (−2)² + 7(−2) + 10 = 4 − 14 + 10 = 0 ✓; 25 − 35 + 10 = 0 ✓.

Жауабы / Ответ: −2; −5

Есеп 3. x² − 2x − 15 = 0

p = −2, q = −15. Қосынды: 2; көбейтінді: −15.

Көбейтінді теріс ⇒ сандардың таңбалары әртүрлі. 15 = 3·5; қосындысы 2 болу үшін үлкені оң: 5 және −3.

p = −2, q = −15. Сумма 2, произведение −15. Произведение отрицательное — числа разных знаков. Сумма 2 получается у 5 и −3.

Тексеру: 25 − 10 − 15 = 0 ✓; 9 + 6 − 15 = 0 ✓.

Жауабы / Ответ: 5; −3

Есеп 4. x² + 3x − 10 = 0

p = 3, q = −10. Қосынды: −3; көбейтінді: −10.

Таңбалары әртүрлі; 10 = 2·5; қосынды теріс ⇒ модулі үлкені теріс: −5 және 2.

p = 3, q = −10. Сумма −3, произведение −10. Знаки разные; сумма отрицательна, значит, отрицательно число с большим модулем: −5 и 2.

Тексеру: 25 − 15 − 10 = 0 ✓; 4 + 6 − 10 = 0 ✓.

Жауабы / Ответ: −5; 2

Есеп 5. x² − 6x + 4 = 0 теңдеуін шешпей-ақ, x₁² + x₂² мәнін тап

Не решая уравнение x² − 6x + 4 = 0, найди x₁² + x₂².

Виет бойынша: x₁ + x₂ = 6, x₁ · x₂ = 4.

Формула: (x₁ + x₂)² = x₁² + 2x₁x₂ + x₂² ⇒ x₁² + x₂² = (x₁ + x₂)² − 2x₁x₂.

Қою: 6² − 2·4 = 36 − 8 = 28.

По Виету: сумма 6, произведение 4. Из квадрата суммы: x₁² + x₂² = (x₁ + x₂)² − 2x₁x₂ = 36 − 8 = 28. Корни находить не нужно.

Жауабы / Ответ: 28

Есеп 6. x² + x − 12 = 0

Мұнда p = 1, q = −12 (x алдындағы коэффициент 1). Қосынды: −1; көбейтінді: −12.

12 = 3·4, 2·6, 1·12. Таңбалары әртүрлі, айырмасының модулі 1: 3 және 4; қосынды −1 болу үшін үлкені теріс: −4 және 3.

p = 1, q = −12. Сумма −1, произведение −12. Знаки разные, модули отличаются на 1 (3 и 4). Сумма −1 — значит, большее по модулю число отрицательно: −4 и 3.

Тексеру: 16 − 4 − 12 = 0 ✓; 9 + 3 − 12 = 0 ✓.

Жауабы / Ответ: −4; 3

Есеп 7. 2x² − 7x + 3 = 0 (a ≠ 1)

a = 2, b = −7, c = 3. Жалпы формула бойынша:

x₁ + x₂ = −b/a = 7/2, x₁ · x₂ = c/a = 3/2.

Таңдау: 3 + 1/2 = 7/2 ✓ және 3 · 1/2 = 3/2 ✓ ⇒ x₁ = 3, x₂ = 1/2.

a = 2, b = −7, c = 3. Сумма −b/a = 7/2, произведение c/a = 3/2. Подбор: 3 + 1/2 = 7/2 и 3 · 1/2 = 3/2. Важно: если a ≠ 1, делим b и c на a.

Тексеру: 2·9 − 21 + 3 = 0 ✓; 2·¼ − 7/2 + 3 = ½ − 3½ + 3 = 0 ✓.

Жауабы / Ответ: 3; 1/2

Есеп 8. 3x² + 8x − 3 = 0

a = 3, b = 8, c = −3. x₁ + x₂ = −8/3, x₁ · x₂ = −3/3 = −1.

Көбейтінді −1 ⇒ сандар кері және қарама-қарсы таңбалы: −3 және 1/3. Қосындысы: −3 + 1/3 = −9/3 + 1/3 = −8/3 ✓.

a = 3, b = 8, c = −3. Сумма −8/3, произведение −1. Произведение −1: числа вида t и −1/t. Подходят −3 и 1/3: их сумма −9/3 + 1/3 = −8/3.

Тексеру: 3·9 − 24 − 3 = 0 ✓; 3·(1/9) + 8/3 − 3 = 1/3 + 8/3 − 3 = 0 ✓.

Жауабы / Ответ: −3; 1/3

Есеп 9. Түбірлері 4 және −7 болатын квадрат теңдеу құр (кері теорема)

Составь квадратное уравнение с корнями 4 и −7 (обратная теорема).

x₁ + x₂ = 4 + (−7) = −3, сонда −p = −3, яғни p = 3.

x₁ · x₂ = 4 · (−7) = −28, сонда q = −28.

Теңдеу: x² + px + q = 0 ⇒ x² + 3x − 28 = 0.

Сумма корней −3, значит p = 3. Произведение −28, значит q = −28. Подставляем в x² + px + q = 0.

Тексеру: 16 + 12 − 28 = 0 ✓; 49 − 21 − 28 = 0 ✓.

Жауабы / Ответ: x² + 3x − 28 = 0

Есеп 10. x² + px + 12 = 0 теңдеуінің бір түбірі 3. p-ны және екінші түбірді тап

Один корень уравнения x² + px + 12 = 0 равен 3. Найди p и второй корень.

Виет бойынша x₁ · x₂ = 12. x₁ = 3 болғандықтан: 3 · x₂ = 12 ⇒ x₂ = 4.

Қосынды: x₁ + x₂ = 3 + 4 = 7 = −p ⇒ p = −7.

Теңдеу: x² − 7x + 12 = 0.

Произведение корней равно 12, значит x₂ = 12 : 3 = 4. Сумма 3 + 4 = 7 = −p, поэтому p = −7. Уравнение: x² − 7x + 12 = 0.

Тексеру: 9 − 21 + 12 = 0 ✓; 16 − 28 + 12 = 0 ✓.

Жауабы / Ответ: p = −7; x₂ = 4

Қорытынды / Итог

Таңбаны қарап сандарды тез табуға болады: көбейтінді оң — таңбалары бірдей (қосындымен бірдей); көбейтінді теріс — таңбалары әртүрлі. Әрқашан тексеріңдер!

Знак произведения подсказывает знаки корней: произведение положительное — знаки одинаковые (как у суммы); отрицательное — разные. Всегда делай проверку!
